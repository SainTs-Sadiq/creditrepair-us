# CreditRepair.US

Responsive CreditRepair.US marketing and service-selection website.

## Features
- White / red / navy brand palette
- Responsive homepage
- Service package cards
- Selected-plan contact page
- Telegram deep link with a pre-filled inquiry
- Email `mailto:` link with a pre-filled subject and message
- FAQ and process sections

## Configuration
Edit `config.js` and replace `YOUR_EMAIL_HERE` with the business email address.

Telegram is configured for `@creditrepair_us`.

## Important
The site is an inquiry flow and does not process payments. It does not guarantee credit-score increases, deletions, or other specific outcomes.
